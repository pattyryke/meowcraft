MEOWCRAFT CLIENT INSTALLER  =^.^=

This copy installs the "core" set. (variant.txt says core or fancy.)
Core:  Sodium, ImmediatelyFast, Mod Menu, Xaero's Minimap + World Map, Jade, AppleSkin,
       Mouse Tweaks, Zoomify, Simple Voice Chat
Fancy: everything in Core + Iris, Fresh Animations, and High/Medium/Low shader packs
Anything these need is downloaded automatically, always the newest versions.

FIRST (everyone): open the Minecraft Launcher once, log in, then CLOSE it.

WINDOWS
1. Unzip this folder anywhere (Desktop is fine).
2. Double-click install.bat.
   - If Windows says "Windows protected your PC", click "More info" -> "Run anyway".

MAC
1. Unzip this folder (double-click the zip).
2. Double-click install.command.
   - If the Mac says it "cannot be opened" or "Apple could not verify", open
     System Settings -> Privacy & Security, scroll down, click "Open Anyway",
     then double-click install.command again.
   - Still blocked? Open Terminal, type   bash   and a space, drag install.command
     into the Terminal window, and press Return.

THEN (everyone)
- Open the Minecraft Launcher, choose "Meowcraft" next to the Play button, press Play.
- Multiplayer -> Meowcraft is already in your server list. Press V for voice chat.
- Fancy only: press O in game to pick a shader (High / Medium / Low), K to toggle shaders.

Run the installer again any time to update everything.
The Meowcraft profile uses its own folder, so your normal Minecraft is untouched.
