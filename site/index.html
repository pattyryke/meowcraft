Get set up once, about 2 minutes

  1. Open the Minecraft Launcher, log in, then close it.
  2. Open PowerShell: Start menu, type PowerShell, press Enter.
  3. Paste this line and press Enter:
    irm https://raw.githubusercontent.com/pattyryke/meowcraft/main/meowcraft-tools/get-windows.ps1 | iex
  4. Pick Normal or Fancy. A cat Play Meowcraft icon shows up on your desktop.
  1. Open the Minecraft Launcher, log in, then close it.
  2. Open Terminal: press Cmd+Space, type Terminal, press Enter.
  3. Paste this line and press Enter:
    curl -fsSL https://raw.githubusercontent.com/pattyryke/meowcraft/main/meowcraft-tools/get-mac.sh | bash
  4. Pick Normal or Fancy. A cat Play Meowcraft icon shows up in your Dock.
  1. Use the Modrinth App, Prism Launcher or ATLauncher? Download a pack file from Downloads below.
  2. In your launcher, choose Add instance → Import and pick the file.
  3. Play. The Meowcraft server is already in the server list.

Pack files don't update by themselves. When the pack number goes up, import the new one (or use your launcher's update button).

From then on, always start Minecraft with the cat icon. It grabs any new mods in a few seconds, then opens the Launcher like normal.

        Change any of these in Options → Controls → Key Binds.

        The meowcraft command

        The cat icon is all most people need. For anything else, type these in a new PowerShell / Terminal window.

        meowcraft updateCheck for new mods right now
        meowcraft statusWhat you have, and whether an update is waiting
        meowcraft switch fancyChange versions (or switch normal)
        meowcraft resetStart fresh. Worlds and screenshots are always kept.
        meowcraft reset --keep_settingsStart fresh but keep settings, keybinds, waypoints and servers
        meowcraft uninstallRemove the icon, Launcher profile and command
        “Mismatched mods” or I can't join

        Run meowcraft update (or just click the cat icon again). If it still won't work, meowcraft reset --keep_settings gives you a clean folder and keeps your settings.

        The game is slow on Fancy

        Press Esc → Options → Video Settings → Shader Packs and pick Meowcraft Low, or turn shaders off. Or switch for good: meowcraft switch normal.

        Nobody can hear me

        Hold Caps Lock while talking, and press V to check that the right microphone is picked and the volume bar moves.
